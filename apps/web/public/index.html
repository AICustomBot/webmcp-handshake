        How Handshake works

        1. The agent (via WebMCP tools) reads room state, searches the synthetic catalog and runs deterministic checks.
        2. It can only propose changes — proposals never touch committed state.
        3. You approve or reject each proposal in this page. Approval records the exact proposal hash.
        4. Apply revalidates everything (expiry, version, hash, budget) and commits atomically.
        5. Protected actions (booking, quotes) need a fresh, single-use human confirmation.
        6. Every step is audited; download the evidence receipt at any time.

        Handshake — WebMCP Challenge demo. All catalog items, prices, bookings and quotes are synthetic. Clearance checks are simplified demo heuristics, not code or professional compliance approvals.
